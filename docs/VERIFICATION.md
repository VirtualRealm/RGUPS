# Проверка портала

## Аккаунты и кабинеты — 12 октября 2026

- 30 unit-тестов: исходные 21 плюс Argon2id, случайные сессии, строгая валидация регистрации, безопасные названия устройств, три серверных рендера форм до hydration и две проверки production-конфигурации без вывода секретов.
- 46 HTTP/integration проверок на локальном сервере и постоянной PGlite: две роли регистрации, cookie, серверный статус PENDING, CSRF, лимит тела, запрет ADMIN, подтверждение почты, однократность ссылок, проверка принадлежности, запрет чужих сессий, отзыв устройств, изоляция оценок, смена/сброс пароля, отзыв прежних ссылок и ограничение попыток входа.
- Обе миграции применены на двух новых локальных базах; seed из официального расписания выполнен повторно. Тестовые аккаунты и учебные записи удалены по их собственным UUID; настоящих пользователей не создавали.
- `dev:local` проверен: новая постоянная база в .local, generate → migrate deploy → seed → Next.js на 127.0.0.1:3000. Внешняя почта не отправлялась.
- Независимый security review выявил четыре ошибки: действующие ссылки после смены пароля, гонки выдачи ссылок/проверки анкеты и общий лимит для всех клиентов. Исправлены; регрессионная проверка старого reset token включена в HTTP-тест.
- ESLint, TypeScript, серверная production-сборка и отдельный статический экспорт прошли. Экспорт: 158 HTML-файлов, 6700 локальных ссылок/ресурсов.
- Статический сайт/HTML содержит явно обозначенный предпросмотр кабинета. Настоящий auth backend не публикуется на статическом хостинге.
- Автономный HTML пересобран: 157 страниц, 30 интерактивных маршрутов, 14 побайтово проверенных ресурсов (9 PDF), 38 268 621 байт; итоговый JavaScript синтаксически корректен.
- Браузерная визуальная проверка и browser E2E не выполнены из-за запрета среды. SMTP-доставка, Docker и полноценный PostgreSQL не проверены; PGlite-проверки не заменяют приёмку на рабочей инфраструктуре.
- Установка по frozen lockfile выполнена повторно успешно. В итоговой локальной базе 68 групп и 0 тестовых аккаунтов после очистки.
- Публикация этого этапа не выполнена: source helper не смог установить TLS-соединение с git.chatgpt-team.site (Schannel/OpenSSL). Прежняя онлайн-версия сохранена; свежие исходники и автономный HTML находятся в outputs.
- Подготовлен выпуск 1.0.0-rc.1: Docker Compose для PostgreSQL/миграций/Node/Caddy, проверка конфигурации перед запуском и соединений БД/SMTP, минимальный healthcheck, security headers и GitHub Actions. Повторно пройдены production build, 30 unit-тестов и 46 HTTP-проверок; повторный migrate/seed не меняет существующие аккаунты. Успех GitHub Actions и контейнеров отдельно не подтверждён.
