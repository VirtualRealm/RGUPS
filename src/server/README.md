# Серверные модули

`db.ts` — Prisma/PostgreSQL; `auth/` — Argon2id, opaque sessions, CSRF, проверка анкет, почта, управление устройствами, API кабинета. Runtime Node.js 24.7+. `policies/rbac.ts` — общая матрица будущих модулей; текущие API дополнительно проверяют назначение курса, владельца записи и статус аккаунта.

Входные серверные модули импортируют server-only. Клиент получает ограниченный DTO. SQL лимитов использует часы PostgreSQL. Выдача/отзыв ссылок и подтверждение анкеты сериализуются на строке пользователя. Не переносить этот backend в браузер или статический экспорт. Deployment: Node.js + PostgreSQL + SMTP. Подробности: docs/ACCOUNTS.md.
